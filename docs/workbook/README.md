# Workbook đã điền của các nhóm

Mỗi nhóm sao chép workbook trống từ [`workbooks/`](../../workbooks/) vào đây rồi điền trong giờ học:

```bash
cp workbooks/WORKBOOK-3.md docs/workbook/nhom-a-session-3.md
```

Đặt tên: `<tên-nhóm>-session-<N>.md`

`rescue.sh` **không đụng vào [`docs/`](../../docs/)**, nên workbook đã điền của nhóm an toàn kể cả khi phải chạy cứu hộ giữa buổi.
