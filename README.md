# AI-Native Application Engineering — Tài liệu học viên

Repo dành riêng cho học viên khóa **AI-Native Application Engineering**. Mỗi buổi học nằm trên một nhánh riêng, phát hành dần theo lịch học — nhánh `main` này không chứa nội dung thực hành.

## Cách lấy tài liệu một buổi học

```bash
git clone --branch buoi-1 --single-branch https://github.com/NgDucLoc/csc-ai-assistant-hoc-vien.git
```

Đổi `buoi-1` thành đúng tên nhánh của buổi đang học. Nếu đã clone `main` từ trước, chuyển nhánh bằng:

```bash
git fetch origin
git checkout buoi-1
```

## Các nhánh hiện có

| Nhánh | Nội dung |
|---|---|
| `buoi-1` | Buổi 1 — From Problem to AI Solution (Lab 0 + Lab 1: AI Opportunity Canvas) |
| `buoi-2` | Buổi 2 — Thiết kế kiến trúc ứng dụng AI (Lab 2: Blueprint + ADR). Bao gồm toàn bộ buổi 1 |

Các buổi tiếp theo sẽ được thêm dần vào bảng trên khi nhánh tương ứng được phát hành.
